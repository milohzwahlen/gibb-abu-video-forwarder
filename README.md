# Video-Weiterleitung

Statische Seite für GitHub Pages, die sofort auf ein YouTube-Video weiterleitet.

## Ziel ändern

In `index.html` die Zeile mit `<meta http-equiv="refresh" content="0; url=...">` anpassen, committen, pushen. Nach ca. 1 Minute ist die neue Weiterleitung live – der QR-Code bleibt gleich.

## Einrichten

Repo → Settings → Pages → Source: *Deploy from a branch*, Branch `main`, Ordner `/ (root)`. URL: `https://milohzwahlen.github.io/gibb-abu-video-forwarder`
